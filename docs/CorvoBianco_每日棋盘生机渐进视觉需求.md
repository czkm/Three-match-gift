# Corvo Bianco — 每日棋盘生机渐进视觉需求

## 1. 目标

当前项目中，每日棋盘的核心视觉语言基本统一：

- 外层木框一致
- 内层格子底色差异较小
- 只有第 2 天葡萄园存在较明显的“成长特效”

这会带来一个问题：

玩家虽然知道天数在推进、建筑在修复，但棋盘本身没有持续“活起来”的感觉。

本次需求目标：

- 让棋盘随着日期推进，逐步从沉寂、荒凉，走向温暖、丰盛、生机勃勃
- 每一天的棋盘都应有明确但不过度的独特气质
- 玩家在进入新的一天时，应直观感受到：
  “不仅场景在恢复，连操作棋盘本身都越来越有生命力”

## 2. 设计原则

### 2.1 渐进，不突变

棋盘视觉不做每天彻底换皮。
保留统一的 Corvo Bianco 棋盘基底，在此基础上逐层增加：

- 光
- 植物
- 纹理
- 温度
- 装饰性细节

### 2.2 棋盘优先服务可读性

任何生机化装饰都不能破坏：

- Tile 识别
- 怪物识别
- 消除反馈
- 技能目标判断

所以所有额外装饰必须满足：

- 透明度受控
- 尽量位于边缘和底层
- 不压住主棋子
- 不与怪物提示层竞争

### 2.3 生机感来源于环境复苏

不是简单换色，而是强调：

- 板缝里长出藤蔓
- 木框变得更润泽
- 格子边缘出现暖光或花粉
- 棋盘局部出现园圃、露水、炉火、丁香、烛光等母题

## 3. 当前实现基础

### 3.1 外层日期色调

文件：
`src/assets/tokens.css`

### 3.2 棋盘内部主题变量

- `boardGrowthProgress`

### 3.3 已存在的葡萄园特例

当前只有第 2 天使用了：

- `board-growth`

- `growth-grape`

这说明项目已经具备：
“棋盘底层叠加环境装饰层”的实现能力。

本次需求建议基于这套方式扩展，不另起新的棋盘组件结构。

## 4. 总体方案

### 4.1 棋盘视觉分三层

#### A. 固定骨架层

始终保留：

- 木框
- 格线
- 深色格底
- 统一操作质感

#### B. 日主题层

每一天都有自己的环境主题底层：

- 藤蔓
- 酒窖粉尘
- 草料与马厩木屑
- 花床与丁香
- 露水与温室暖雾
- 夕照与栏杆光影
- 炉火与烟气
- 紫丁香与烛光

#### C. 修复进度层

每一天的棋盘不只是切换主题，还应随着 `repairProgressPct` 增强表现：

- 初期弱
- 中期明显
- 接近完成时最饱满

也就是：

- 每一天 = 一个主题
- 每个主题 = 随修复进度生长或增强

## 5. 每日棋盘视觉节奏

### Day 1 庭院

关键词：

- 荒草初清
- 石缝
- 微弱晨光

表现：

- 棋盘仍偏暗、偏旧
- 格线略粗糙
- 边角有少量苔痕、碎叶
- 进度越高，边缘出现更干净的石路感和轻微暖光

玩家感受：

- 刚开始整理，一切还很荒，但已经能看见秩序

### Day 2 葡萄园

关键词：

- 藤蔓回生
- 新叶
- 葡萄初现

表现：

- 保留当前葡萄园成长层
- 升级成正式日主题模板
- 进度越高，藤蔓更多、叶片更饱满、葡萄更明显

玩家感受：

- 第一次明确感到棋盘“长东西了”

### Day 3 酒窖

关键词：

- 木桶
- 酒香
- 琥珀色尘粒

表现：

- 底层偏木质、酒红、琥珀暖棕
- 棋盘边缘可出现酒滴、木桶箍线、浮尘粒子
- 高进度时格子边缘出现更温暖的酒窖灯火反光

玩家感受：

- 从野外恢复过渡到有生活气味的室内空间

### Day 4 马厩

关键词：

- 干草
- 木栏
- 温热尘埃

表现：

- 棋盘边缘出现干草束、木栏投影
- 底色更暖，加入浅金色草料粉尘
- 高进度时有轻微浮尘和阳光束感

玩家感受：

- 环境更柔软、更有人照料过的温度

### Day 5 花园 / 丁香

关键词：

- 花床
- 丁香
- 清香
- 柔紫色

表现：

- 棋盘开始明显从“修复”转向“装点”
- 边缘出现花瓣、嫩枝、浅紫色柔光
- 格线和背景中引入丁香色层次

玩家感受：

- 不只是能住，而是开始值得停留

### Day 6 温室

关键词：

- 玻璃暖雾
- 露水
- 嫩芽
- 潮润生命力

表现：

- 棋盘表层有轻微玻璃反光感
- 边缘加入雾气、露珠、幼苗感
- 进度提升时绿色饱和度和湿润感增强

玩家感受：

- 生命开始稳定生长，不再只是被动恢复

### Day 7 露台 / 日落

关键词：

- 晚霞
- 金光
- 风

表现：

- 棋盘加入斜向暖光和长阴影
- 边缘出现露台栏杆投影感
- 高进度时有柔和的日落粒尘或空气流动感

玩家感受：

- 棋盘第一次有明确的时间感和诗意

### Day 8 厨房 / 炉火

关键词：

- 火光
- 烟气
- 热度
- 食物气息

表现：

- 棋盘整体变得更暖
- 边缘带有橙金色炉火反光
- 轻微烟气或热流效果仅放在底层
- 高进度时局部有火焰般的脉动暖色

玩家感受：

- 生机从自然生长，过渡到“有人生活的温度”

### Day 9 紫丁香客房

关键词：

- 柔紫
- 烛光
- 安宁
- 祝福

表现：

- 棋盘底色更偏柔和室内和丁香色调
- 低层出现浅紫光晕、布料般柔纹、烛光感
- 保持干净，不与仪式层冲突

玩家感受：

- 修复完成，不再是劳作现场，而是承载祝福的空间

## 6. 动态要求

### 6.1 当天进度驱动

所有日主题装饰都应与 `repairProgressPct` 关联：

- `0.0 - 0.25`：轻微主题提示
- `0.25 - 0.6`：主题元素逐渐成形
- `0.6 - 1.0`：主题元素饱满
- `repairing` 阶段：允许有一次更明显的呼吸或生长强化

### 6.2 新一天切换

进入新一天时，棋盘主题要立刻切换，但不要硬切：

- 使用现有 `transition` 做颜色与底纹过渡
- 避免突然闪屏或突然换材质

### 6.3 不影响玩法

以下元素必须严格克制：

- 浮动粒子数量
- 高亮面积
- 大面积纯亮色覆盖
- 容易被误认成可点击目标的装饰

## 7. 技术实现建议

### 7.1 继续以 `GameBoard.vue` 为主实现

文件：
`src/components/Board/GameBoard.vue`

建议继续在该文件中扩展日主题层，不新建新的棋盘组件。

### 7.2 从单一 `boardGrowthTheme` 升级为日主题枚举

当前更像只支持：

- `vineyard`

建议升级为：

- `courtyard`
- `vineyard`
- `cellar`
- `stables`
- `garden`
- `greenhouse`
- `terrace`
- `kitchen`
- `lilacSuite`

统一返回：

- `boardTheme`
- `boardThemeProgress`

### 7.3 每个主题只保留少量辨识元素

不建议每天都堆很多层。
每一天只保留 2-4 个最有辨识度的元素。

### 7.4 使用 CSS 变量统一主题控制

建议增加变量：

- `--board-accent-1`
- `--board-accent-2`
- `--board-atmo-glow`
- `--board-decor-opacity`

由 `boardThemeStyle` 输出，CSS 负责最终表现。

## 8. 验收标准

完成后应满足：

1. 玩家不看文字，仅看棋盘，也能明显感觉 Day1 到 Day9 在逐渐恢复生机。
2. 每一天棋盘都有自己的主题识别点，不只是换个色相。
3. 第 2 天不再是唯一有明显变化的一天。
4. 所有日主题都不影响 Tile、怪物、技能目标辨识。
5. 修复进度提高时，主题元素会逐渐增强，而不是固定不变。
6. 第 9 天棋盘应是最完整、最柔和、最有安定感的版本。

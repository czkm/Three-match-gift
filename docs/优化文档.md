# 《白鸦葡萄园》PC端专属深度打磨方案

## ——一份只用鼠标打开的生日礼物

## 一、核心设计原则

### 1.1 礼物三原则

| 原则                 | 含义                                                         |
| :------------------- | :----------------------------------------------------------- |
| **打开即懂**         | 不需要教程，不需要键盘，不需要思考。鼠标移上去，一切自然发生。 |
| **每一次点击都值得** | 操作本身是愉悦的。不是“为了消除而消除”，而是“每一次触碰都在让庄园变好一点”。 |
| **她是唯一的玩家**   | 不考虑大众适配、不考虑通用设计、不考虑男性玩家。所有细节只为一个人——那个收到这份礼物的人。 |

## 二、鼠标手感深度设计

### 2.1 光标即手指

当游戏启动，标准系统光标消失，替换为自定义光标：**一片轻轻旋转的白鸦羽毛**。

| 行为             | 光标变化                                                     |
| :--------------- | :----------------------------------------------------------- |
| 进入棋盘区域     | 羽毛亮度 +15%，边缘泛起极淡金色光晕                          |
| 悬停任一方块     | 羽毛缩小至 90%，方块同步亮起暖金边框（0.05s 淡入），如同“羽毛轻轻触碰了它” |
| 按住方块开始拖拽 | 羽毛消失，方块被“捏起”——轻微缩小至 92%，产生 1px 内阴影      |
| 拖拽中移向相邻格 | 目标格同步微亮，形成一条极细的暖金虚线连接两格               |
| 松手确认交换     | 羽毛重新出现在松手位置，轻微放大后恢复（0.15s）              |
| 移出棋盘区域     | 羽毛恢复原始亮度，不带光晕                                   |

**设计意图**：她不是在操作鼠标。她是用一片羽毛，轻轻拂过葡萄园。

### 2.2 拖拽的“呼吸感”

| 阶段          | 手感描述                                                     |
| :------------ | :----------------------------------------------------------- |
| 拾起          | 方块不是被提起，而是“被捏了一下”——缩小到 92% 的过程用缓出曲线（0.1s），像指尖轻轻按进一块软木 |
| 拖动          | 方块跟随羽毛移动，但始终与相邻格中心连线贴合。拖到正确方向时，方块会自动“滑入那条轨道”——5px 的轻微吸附，像葡萄藤自己缠上了架子 |
| 松手·匹配成功 | 方块先完成交换（0.15s），然后原地轻跳 2px，跳起时闪过一点金色碎光 |
| 松手·匹配失败 | 方块慢慢滑回原位（0.25s 缓出），不发红光，不弹错误提示。只是滑回去，像水轻轻退了一步。同时两个方块短暂泛起极淡的暖橙色（透明度 12%，持续 0.2s），像夕阳在说：“这条路不通，换一条。” |

**设计意图**：失败不是惩罚。是在葡萄园里走路，踩到一块松掉的石板。换一块就好。

### 2.4 双击彩蛋

| 双击目标                   | 效果                                                     |
| :------------------------- | :------------------------------------------------------- |
| **双击棋盘中任意葡萄方块** | 葡萄串轻轻晃动，落下两片极小的叶子（纯装饰，不影响棋盘） |
| **双击场景中的萝卜**       | 萝卜从马厩窗口缩回去，过三秒又伸出来，伴随一声轻哼       |
| **双击场景中的白鸦**       | 它歪头看了她一眼，叫一声，飞走十秒后回来                 |
| **双击露台上的两把椅子**   | 椅子轻轻晃一下，像有人刚刚坐下                           |
| **双击花瓶里的紫丁香**     | 一片花瓣飘落，飘出棋盘，落进场景底部消失                 |

**设计意图**：这些不是“功能”。这些是她在庄园里走动时，随手拨弄花叶的那种感觉。游戏不会告诉她这些彩蛋的存在。她需要自己发现——就像在真的花园里。

## 三、UI交互逻辑优化

### 3.1 一切用鼠标，一眼就懂

| 交互           | 实现                                                         |
| :------------- | :----------------------------------------------------------- |
| 点击能力图标   | 能力激活，图标变亮（带暖金边框），光标变羽毛 + 对应技能微光。再次点击棋盘或按原图标取消 |
| 悬停能力图标   | 浮出小提示框，仅有技能名和八个字以内的说明（如“点一粒，周围一圈全结满”） |
| 悬停步数       | 显示“今天还能走 X 步”，字体极轻，不跳动                      |
| 悬停资源进度条 | 显示“还需要 X 块石材”，无任何催促语气                        |
| 悬停建筑名称   | 显示建筑当前状态，如：“庭院·石路重新露出来了”                |
| 悬停天数       | 显示当前日期感和时间感，如：“第五天·午后阳光”                |

**所有可交互元素必须在鼠标悬停 0.08s 内响应。没有任何延迟。**

### 3.2 HUD布局





- **步数数字**不用红色、不用感叹号。步数降至 5 时，数字只是字体微微变细，颜色从暗金过渡到暖橙。不制造紧张。
- **资源进度条**不使用“血条式”红绿，而用羊皮纸质感的长条，填充色是深木色渐变为暗金色。像木头在被打磨，不像数值在增长。
- **能力按钮**不用冷冰冰的方形按钮，而是九个小圆形徽记，像葡萄园里随手捡到的石片，上面刻着不同的符号。

### 3.3 对话框——他只对她说话

杰洛特的自言自语在屏幕底部显示。

| 细节     | 实现                                                 |
| :------- | :--------------------------------------------------- |
| 背景     | 半透明羊皮纸，边缘模糊，像被夕阳照透的旧信纸         |
| 字体     | 衬线体，深棕色，字号不大                             |
| 出现方式 | 打字机效果，一字一字浮现（每字 0.04s），可以点击跳过 |
| 停留时间 | 全部打完后停留 2s，然后缓缓淡出（0.5s）              |
| 文案长度 | 每句不超过两行。克制。不煽情。                       |

**示例**：

> 萝卜站在歪掉的马厩门口。它没叫，只是慢慢踱进去，在墙角转了两圈，然后把头从破窗户伸出来。

他说完这句话，对话框淡出。没有音乐变化，没有特效。只有安静。

## 四、平衡性与游戏性——藏在温柔里的深度

### 



### 4.3 跨天——允许她今天不想玩

每天 20 步。用完了，建筑没修好？



```
杰洛特放下工具。
显示：“今天累了。明天继续。”
建筑进度保留。
棋盘明天刷新。
能力明天重置。
```



**没有任何惩罚。没有任何损失。** 如果她今天不想玩完，关掉网页。明天打开，一切还在等她。

## 五、结局——礼物的最后一句话

第九天，紫丁香客房修好。

她看到：

- 露台上从一把椅子变成了两把。
- 一只白鸦落在栏杆上。
- 紫色传送门在庭院中安静地打开。
- 叶奈法走出来。她看向修好的庄园。

> 叶奈法：“……不算糟。”
>
> 杰洛特：“藤还没爬满。”
>
> 叶奈法：“我有很多时间。”
>
> （长停顿。风吹过葡萄藤。）
>
> 杰洛特：“……嗯。”

画面渐渐暗下来。

屏幕正中央，浮现她名字的最后一个字，然后淡出。

下方出现一行字：

> 献给你。

然后是预设的文案（她看不到你选了哪句，但你选了）：

> 比好酒更好的，是喝第一杯的人。

画面停留 30 秒。不强制退出，不跳转任何页面。她可以一直看。

她关掉网页的时候，葡萄园还在那里。两把椅子还在那里。夕阳还在那里。

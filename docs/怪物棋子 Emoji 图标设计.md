# 《白鸦葡萄园》怪物棋子 Emoji 图标设计（单 Emoji 版）

## 设计原则

每个怪物只使用一个原生 Emoji 作为棋子显示，通过 CSS 动画实现待机与消除效果，简洁、清晰、不干扰棋盘识别。

## 一、怪物 Emoji 对照表

| 怪物   | Emoji | 说明                                                   |
| :----- | :---- | :----------------------------------------------------- |
| 孽鬼   | 👺     | 红色天狗面具——大耳、圆眼、龇牙，符合孽鬼被发现的尴尬感 |
| 水鬼   | 🧟     | 僵尸——灰绿色皮肤、呆滞眼神，与水鬼泡胀的类人外形契合   |
| 食尸鬼 | 🧌     | 山怪——驼背、大鼻子，适合从地下挖出来的茫然生物         |
| 小雾妖 | 🌫️     | 雾气——半透明幽浮感，无固定形状，迷路的雾               |
| 迪精   | 🧞     | 巨灵——阿拉伯神话中的精灵，与迪精“瓶中灵体”的原型一致   |

## 二、待机 CSS 动画

| 怪物     | 动画名称        | 动画描述                                                     | 时长      |
| :------- | :-------------- | :----------------------------------------------------------- | :-------- |
| 👺 孽鬼   | `nue-giggle`    | 轻微左右晃动，偶尔向上小跳 2px                               | 1.2s 循环 |
| 🧟 水鬼   | `drowner-drip`  | 缓慢下沉 1px 再浮起，模拟水中漂浮；同时透明度在 90%~100% 间变化 | 2s 循环   |
| 🧌 食尸鬼 | `ghoul-breathe` | 背脊起伏：轻微缩放（100%→105%→100%），模拟呼吸               | 1.5s 循环 |
| 🌫️ 小雾妖 | `fog-drift`     | 持续左右漂移 ±3px，透明度在 60%~80% 间波动，雾丝向上飘升     | 3s 循环   |
| 🧞 迪精   | `djinn-pulse`   | 脉动缩放 100%→110%→100%，同时添加金色光晕（`text-shadow`）渐变 | 0.8s 循环 |

## 三、消除动画（通过 CSS 类触发）

| 怪物     | 消除动画关键帧                                               |
| :------- | :----------------------------------------------------------- |
| 👺 孽鬼   | 1. 替换为 😱；2. `transform: translateY(10px) scale(0)` + `opacity: 0`；3. 地面出现 🕳️（伪元素）；4. 洞消失 |
| 🧟 水鬼   | 1. 替换为 😱；2. `transform: translateY(-6px)`；3. `transform: scale(1.5)` 同时 `opacity: 0` + 💧伪元素四散 |
| 🧌 食尸鬼 | 1. `filter: brightness(1.5)`；2. 快速抖动 `translateX(±2px)` 两次；3. `transform: translateY(8px) scaleY(0)` + 土色方块（伪元素）从下方吞没 |
| 🌫️ 小雾妖 | 1. 膨胀：`transform: scale(2)` + `opacity: 0.9`；2. 瞬间 `opacity: 0` + 一粒✨从中心飘出并渐隐 |
| 🧞 迪精   | 1. 光团炸开：`transform: scale(2)` + `opacity: 0`；2. 数十粒金色光点（✨伪元素）向上飘散；3. 短暂出现迪精人形剪影（用 `text-shadow` 实现）后消失 |

## 四、消除后的残留效果

消除后原格子上短暂保留一个视觉残留，表示“这里曾有东西”：

- 👺 孽鬼 → `🕳️` 土洞，0.3s 消失
- 🧟 水鬼 → `💧` 小水渍，0.3s 消失
- 🧌 食尸鬼 → 🟫 土色方块，0.3s 消失
- 🌫️ 小雾妖 → ✨ 一粒微光向上飘出棋盘
- 🧞 迪精 → 三片金色羽毛（🪶）缓缓向上飘离屏幕

## 五、CSS 实现示例（以孽鬼为例）

css

```
.monster-nue {
  font-size: 48px;
  line-height: 48px;
  animation: nue-giggle 1.2s infinite;
}

@keyframes nue-giggle {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(1px); }
  75% { transform: translateX(-1px); }
  50% { transform: translateY(-2px); }
}

.monster-nue.removing {
  animation: none;
  --emoji: '😱';
  /* 通过伪元素或内容替换实现表情变化 */
}
```



由于棋盘使用 Canvas 渲染，这些 CSS 动画建议转换为 Canvas 上的帧动画或缓动函数调用，由 `renderer.js` 直接处理。

## 六、Emoji 来源与兼容性

所有选用 Emoji 均来自 Unicode 标准，在 Windows/macOS/iOS 上均可正常显示：

- 👺 U+1F47A
- 🧟 U+1F9DF
- 🧌 U+1F9CC
- 🌫️ U+1F32B
- 🧞 U+1F9DE
